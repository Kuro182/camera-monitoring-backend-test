# Legacy

В этой части находится разбор и переработка метода загрузки событий из удалённого WCF-сервиса.

Будут рассмотрены:

- корректность временных интервалов;
- особенности синхронного сетевого вызова;
- обработка временных ошибок;
- удаление дубликатов;
- сортировка и алгоритмическая сложность;
- постепенный перенос legacy-кода в современный сервис.
